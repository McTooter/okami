# Noir Pulse Kinetic Material

Noir Pulse now uses an original **red haze + black cut-panel + white seam** motion vocabulary. It responds to material entry and navigation changes instead of leaving static comic-style decoration on every surface.

The haze has a slow, low-opacity drift so it remains atmospheric rather than noisy. A diagonal black panel settles in when Noir Pulse becomes active, while a narrow white seam performs a brief, smooth navigation sweep. All decorative layers have `pointerEvents="none"`; direct manipulation stays unblocked.

When motion reduction is enabled, repeated movement and sweep durations are removed. The material retains only a low-contrast, stationary color cue so navigation remains legible and calm.
